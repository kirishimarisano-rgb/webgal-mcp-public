# INDEX.md 约定

库根下的 `INDEX.md` 采用 UTF-8 Markdown。以下是单条记录的完整示例。

```markdown
# WebGAL 素材库

<!-- webgal-librarian v1 -->

## bgm/quiet evening.ogg
- 名称: 晚自习之后
- 类型: BGM
- 描述: 适合在空教室道别时使用
- 标签: 安静、离别、放学后
- 来源: 未知
- 授权: 未知
```

每个二级标题包含一个完整、区分拼写的库内相对路径，目录分隔符为 `/`。同名文件可放在不同子目录。索引随整个库移到其他位置后仍可使用。保留格式标记、标题和六个字段名。字段值写在同一行，标签以「、」分隔。可在条目下面另写普通段落作为备注，重扫只追加新路径。

类型取值为「背景」「立绘」「BGM」「音效」「图片待分类」「音频待分类」。消费者从所选库根解析相对路径，推荐前检查可读性。缺失文件重新出现在原路径后，沿用原条目和标注。
